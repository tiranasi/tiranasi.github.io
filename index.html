SkyMate

A stargazing assistant for smart glasses, combining orientation-aware sky rendering, manual north calibration, voice interaction, and LLM tool calling for guided target finding.

Project overview

Orientation: quaternion-based view calculation and manual calibration. Interaction: voice search, edge guidance, and AI question answering.

Typhoon Typhoon tracking on smart glasses Tracks · Wind circles · Maps

Typhoon

A typhoon tracking application for Rokid smart glasses, combining a FastAPI data service with maps of historical and forecast tracks, current positions, and wind circles. The interface supports map zoom and track-point selection.

Smart glassesFastAPIGeospatial visualization
API code ↗
Project overview

The FastAPI backend provides normalized, cached typhoon data from China's National Meteorological Center. The AIUI frontend combines offline map layers, Canvas rendering, and button-driven navigation.
